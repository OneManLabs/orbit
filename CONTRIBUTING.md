# Contributing

## Prepare a change

1. Open an issue for a large change.
2. Do not add a private model or camera image.
3. Do not add an API key, password, or access token.
4. Keep camera processing in the browser unless the change has an approved privacy design.

## Verify a change

1. Run `npm ci`.
2. Run `npm run build`.
3. Test pointer controls without a camera.
4. Test gesture controls with a camera.

## Documentation rules

Use short, direct sentences. Use one term for one item. Put one action in each instruction. Define an abbreviation before you use it.
